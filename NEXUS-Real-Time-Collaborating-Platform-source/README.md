# NEXUS – Real-Time Collaborating Platform

NEXUS is a real-time collaboration platform designed for smooth communication and teamwork.

## Features
- Real-time collaboration interface
- Room-based collaboration
- Responsive React UI
- Socket.io-ready architecture
- Scalable project structure

## Tech Stack
React, Vite, Socket.io, REST APIs, MongoDB, Tailwind CSS

## Live Demo
https://nexus-liard-theta.vercel.app/

## Run Locally

```bash
npm install
npm run dev
```
